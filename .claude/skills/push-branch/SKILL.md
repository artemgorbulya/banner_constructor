---

Кроки:
1. Запусти `git status` і `git diff --stat` щоб побачити що змінилось
2. На основі змін придумай коротку англійську назву гілки у форматі `kebab-case` (наприклад `remove-banner-library`, `fix-export-modal`, `add-zoom-controls`)
3. Запусти `git log --oneline -3` щоб побачити стиль повідомлень у цьому репо
4. Створи гілку: `git checkout -b <назва-гілки>`
5. Додай всі змінені файли: `git add` кожен файл явно (не `git add -A` — щоб не потрапили випадкові файли)
6. Зроби коміт з осмисленим повідомленням що пояснює ЧОМУ, не ЩО. Додай Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>
7. Запуш: `git push -u origin <назва-гілки>`
8. Повідом яку гілку створив і які файли потрапили в коміт

Якщо немає незакомічених змін — повідом про це.
